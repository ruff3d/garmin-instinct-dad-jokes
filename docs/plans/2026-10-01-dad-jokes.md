# Dad Jokes implementation plan

**Goal:** Build a Monkey C activity data field for Instinct 3 Solar (45 mm and 50 mm).

**Architecture:** A background service requests one joke from https://icanhazdadjoke.com/ and returns validated text to the foreground. The foreground persists the last good joke, wraps text using actual font widths, and cycles pages every eight seconds. Network errors preserve the cached joke. No account or API key is needed by the joke service.

**Tech stack:** Monkey C, Connect IQ 9.2 SDK, Toybox Background, Communications, Application.Storage, WatchUi.DataField.

1. Confirm device target, background restrictions, and display geometry in the official SDK.
2. Write Monkey C tests for malformed responses, bounded text, whitespace normalization, wrapping long words, pagination, and failed refreshes retaining cached text.
3. Implement response validation, background fetching, foreground scheduling/cache, and monochrome paginated display.
4. Compile with warnings enabled and run native tests in the Garmin simulator if the signed-in device profile is available.
5. Document build, simulator testing, sideloading, phone connectivity, refresh interval, and verification limitations.

## Design decisions

- Both Solar sizes use `instinct3solar45mm`; do not target AMOLED.
- Use recurring five-minute temporal background events (Garmin's minimum interval). The first download can take five minutes; recurring scheduling survives a background task being killed or timing out.
- Prefer an activity screen with one field. Keep full-screen content below the Instinct's upper-right subwindow. Smaller fields paginate with fewer lines.
- Retain the last valid joke after HTTP errors, malformed bodies, or disconnection. Reject overlong responses rather than cutting off the punchline.
- Delete the temporal registration when the field stops. No GPS, health, or activity data is sent.
- The SDK is available locally, but Garmin's device download API requires user sign-in. Never substitute another watch profile for final device verification.
